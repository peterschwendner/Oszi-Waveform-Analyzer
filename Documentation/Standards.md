# External standards and vendor documentation

This software interoperates with oscilloscopes and implements published standards and instrument protocols. Copyrighted standards and vendor manuals are referenced rather than mirrored in this repository.

## Standards

- ISO/IEC 7813 — Identification cards — Financial transaction cards. Obtain from ISO.
- ISO/IEC 7816 — Identification cards — Integrated circuit cards. Obtain from ISO.
- ISO 11898-1 — Road vehicles — Controller area network (CAN), Part 1. Obtain from ISO.
- USB Test and Measurement Class (USBTMC). Obtain from the USB Implementers Forum.

## Vendor documentation

Use current programming guides and protocol manuals supplied by Bosch, Rigol, and Rohde & Schwarz / HAMEG.

Command names, protocol identifiers, numeric constants and data formats used by the source code are included for interoperability. External standards and manufacturer manuals are not distributed under this project's GPL license.
