# Rigol DS1000Z USB descriptor summary

This file records the USB descriptor values used while developing USBTMC support. It replaces an HTML report generated by USBlyzer so that the repository contains only the relevant factual descriptor data.

## Device

- USB speed observed: High Speed (480 Mbit/s)
- Vendor ID: `0x1AB1` (Rigol Technologies)
- Product ID: `0x04CE`
- USB version: 2.0
- Device class: class information supplied by interface descriptors
- Maximum packet size for endpoint 0: 64 bytes

## Interface 0

- Interface class: `0xFE` — application-specific
- Interface subclass: `0x03` — USB Test & Measurement
- Interface protocol: `0x01` — USB488
- Number of endpoints: 3

## Endpoints

- `0x81`: IN, Interrupt, 64-byte maximum packet size
- `0x82`: IN, Bulk, 64-byte maximum packet size
- `0x03`: OUT, Bulk, 64-byte maximum packet size

These values are factual observations from the device descriptor and are included for interoperability and debugging.
